# Legacy Studio registration helper

Requires Windows, Python 3.10+ with the `py` launcher, and an installed GoPro Studio or CineForm Studio.

1. Run **Start registration bypass.cmd** and leave its window open.
2. Open Studio, select **Help > Device Window > Refresh**, then use the update controls.
3. When finished, press **Ctrl+C** in the script window to restore the original setting.

If you closed the window forcibly, run **Restore registration.cmd** afterwards. Stop any running helper before restoring or starting it again.
